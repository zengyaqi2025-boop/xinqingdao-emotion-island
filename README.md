# 心晴岛：情绪和解冒险

鲁美艺术疗愈策展人高研班展厅互动原型。观众先选择当下主情绪，再进入对应的 3 关生命流动路线，每关获得一个艺术疗愈锦囊。

它适合放在展厅大屏或电脑上体验，也可以部署到 GitHub Pages 后生成二维码，让观众用手机进入互动。

## 现场 30 秒介绍

我们把艺术疗愈做成了一个可以玩的互动体验。观众先选择今天的主情绪，比如焦虑、恐惧、委屈、疲惫或孤独，然后进入对应的情绪路线。每条路线由 3 个小关卡组成，每关都有不同的小怪物、障碍和缓解方式。情绪不是敌人，玩家不是消灭它们，而是靠近、看见、安抚，最后带着锦囊继续往前走。

在「十年：生命的流动」展览语境中，它可以作为一个轻量的 AI 时代艺术疗愈互动装置：让观众感受到科技不是冷冰冰的工具，也可以成为自我觉察与情绪陪伴的入口。

## 怎么玩

- 方向键左右移动。
- 空格或上方向键跳跃。
- 下方向键或 `S` 下蹲，钻过低矮障碍。
- 点击右上角「音乐」开启氛围音乐和轻音效。
- 收集呼吸星星，增加照顾能量；星星不阻止通关，但会影响锦囊品质：微光、暖光、满星。
- 靠近情绪小怪物，把它们安抚。
- 跳过障碍，或钻过低洞；撞到障碍会损失能量。
- 每条路线 3 关，每关安抚 3 个小怪物后，走到出口获得锦囊。
- 最后会获得一段“你被看见了”的情绪旅程总结。
- 手机上可以用底部按钮操作。

## 展厅使用方式

- 大屏展示：用电脑打开网页，连接展厅大屏或投影。
- 手机扫码：部署到 GitHub Pages 后，把网页链接生成二维码放在展签旁。
- 现场话术：请选择你此刻最接近的一种情绪，进入一段小小的生命流动旅程。
- 数据边界：当前版本不收集个人信息，只做体验与觉察；后续如需收集联系方式，建议接入独立表单二维码。

## 当前 MVP

- 5 个情绪入口：焦虑、恐惧、委屈、疲惫、孤独。
- 每个入口对应不同的 3 关路线。
- 可移动、跳跃、镜头跟随。
- 可下蹲钻过低矮障碍。
- 每关 3 个具象化情绪小怪物。
- 每关 6 个呼吸星星。
- 障碍物与能量损耗。
- 障碍碰撞反馈：震屏、弹开、能量扣除、浮动提示。
- 每次选择同一种情绪，也会随机出现不同的“今日主题”和星星位置微变化。
- 情绪数值面板：压力、焦虑、孤独、恢复会随玩法变化。
- 能量值影响手感：低能量移动和跳跃变弱，高能量更轻盈并出现光晕。
- 浏览器内置生成氛围音乐，不依赖外部音频版权素材。
- 星星、安抚、碰撞、通关均有轻音效反馈。
- 每个锦囊都包含一个艺术疗愈小练习。
- 结尾会根据情绪数值给出继续自我照顾或后续艺术疗愈探索提示。
- 碰撞触发安抚文案。
- 能量、安抚进度、关卡进度。
- 每关结束获得一个情绪锦囊。
- 锦囊背包和最终旅程总结。

## 本地运行

```bash
python3 -m http.server 8790
```

然后打开：

```text
http://localhost:8790
```

## GitHub Pages 发布

1. 将本文件夹作为 GitHub 仓库推送。
2. 在 GitHub 仓库中进入 `Settings` -> `Pages`。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待 GitHub 生成网页链接。

## 后续可以商业化的方向

- 每日情绪关卡：每天根据用户状态生成一个小关卡。
- 情绪图鉴：安抚过的情绪会进入图鉴，形成长期自我觉察记录。
- 咨询师/教练版：把用户的游戏路径转化为情绪陪伴记录。
- 社群版：朋友之间互相赠送“呼吸星星”和陪伴道具。
- 内容版：每个关卡生成一张可分享的通关情绪海报。

## 产品边界

这个产品只做日常情绪陪伴和自我觉察，不做心理诊断，不替代专业医疗或心理咨询。如果用户出现强烈自伤风险，应引导其立刻联系可信任的人或当地紧急服务。
